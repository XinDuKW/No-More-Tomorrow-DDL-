# NoMoreTomorrow 桌面便签 · EXE 版

把原来的 `Activities.html` 包装成了一个原生桌面软件（Electron）。
**html 只改了 `<title>` 那一行（软件名）**，页面本身的布局、样式、逻辑一行没动，所有桌面能力都在外面一层壳里实现。

> **从 NoTomorrowMe 升级过来的**：软件名改成了 `NoMoreTomorrow`，其它一切都自动处理好了 ——
> 旧的配置文件夹 `NoTomorrowMe-Data` 会在首次启动时**自动改名**为 `NoMoreTomorrow-Data`（便签内容原样保留），
> 旧的开机自启注册表项也会被自动清理并重建。你不需要手动搬任何数据。

---

## 一、三种用法，按需选一个

| 文件 | 适合谁 | 说明 |
|---|---|---|
| `NoMoreTomorrow-Setup-1.0.0.exe` | **推荐** | 安装版。双击安装（可选安装目录），自动建开始菜单 + 桌面快捷方式，带卸载程序。启动最快。 |
| `NoMoreTomorrow-Portable-1.0.0.exe` | 不想安装 | 单文件便携版。放哪儿都能跑，数据存在它旁边。**每次启动都要解压到临时目录，实测约 12 秒**（绿色版只要 1.4 秒）。 |
| `NoMoreTomorrow-绿色版\NoMoreTomorrow.exe` | 要最快启动 | 解压即用的文件夹版，双击就跑。数据固定存在它旁边的 `NoMoreTomorrow-Data` 里。 |

> 未做数字签名，首次运行 Windows SmartScreen 可能提示 —— 点「更多信息 → 仍要运行」即可。

---

## 二、你要的每一条都在

- **一个进程，多个便签窗口**：再次双击 exe 不会开第二个进程，而是让已有进程**再开一个窗口**（单实例锁 + 进程内多窗口）。
- **多个便签同时存在**：每个窗口默认绑定一个**不同的便签（标签页）**；例如开两个窗口，一个显示「便签1」，一个显示「便签2」，互不干扰。任一窗口改内容，其它窗口会**实时同步刷新**。
- **独立配置文件夹**：见第四节，三种用法各有自己的数据目录，与系统里其它软件完全隔离。
- **开机自启**：首次运行**默认开启**（写注册表 `HKCU\...\CurrentVersion\Run` 下的 `com.nomoretomorrow.memo`）。托盘菜单里可随时勾选/取消；exe 挪了位置，下次启动会自动修正自启路径。
- **记忆位置 / 大小 / 数量**：移动、缩放、开关窗口都会**立刻原子写入** `windows.json`（移动缩放 250ms 防抖，关窗/退出/关机立即落盘）。所以**任务管理器强杀、断电、直接关机都没关系** —— 下次打开还是原来那几个窗口、原来的位置和大小。
- **便签内容同样是文件级持久化**：不再依赖浏览器 localStorage，每次改动写入 `store.json`（120ms 防抖 + 原子替换），强杀最多丢最后 0.1 秒的输入。

## 三、操作方式

| 操作 | 方法 |
|---|---|
| 移动窗口 | 拖**便签顶部的小把手**（顶部中间，悬停会变亮）；或拖**标题那一行**的空白处；或拖右上角 **⠿** |
| 缩放窗口 | 拖窗口**四条边 / 四个角**（约 4px 热区，鼠标会变成缩放光标），过程中右下角会实时显示尺寸 |
| 新建窗口 | 右上角 **＋**，或托盘「新建便签窗口」，或 `Ctrl+N`，或再双击一次 exe |
| 置顶 | 右上角 **📌**（点亮 = 置顶），或托盘「窗口置顶」（对所有窗口生效） |
| 最小化 | 右上角 **–** |
| 关闭当前窗口 | 右上角 **✕** |
| 最大化 / 还原 | 双击顶部小把手或 **⠿** |
| 退出整个软件 | 托盘「退出（关闭全部窗口）」，或 `Ctrl+Q`，或关掉所有便签窗口（关掉最后一个会自动退出） |

右上角那排小按钮平时半透明，鼠标移上去才完全显示。

> **为什么拖动要专门做把手，而不是整个便签随便拖？** 因为这个页面用了 `backdrop-filter`/`isolation` 等
> 合成特性，配上透明无边框窗口后，Windows 的原生拖拽区（`-webkit-app-region: drag`）会把按钮点击
> 一起吃掉（表现为"点哪儿都没反应"）。所以移动和缩放改成自己实现：按下后由主进程跟随真实光标
> 移动窗口 —— 按钮点击 100% 不受影响。

**托盘菜单**（任务栏右下角图标，左键单击 = 显示全部窗口）：

- 新建便签窗口
- 显示全部窗口（n）
- 窗口置顶
- 开机自启
- 打开配置文件夹
- 退出

## 四、数据 / 配置文件在哪

每个版本都是**独立的配置文件夹**，里面就这几个文件：

| 文件 | 内容 |
|---|---|
| `store.json` | 便签内容（标题、任务、日期）+ 全部外观设置 |
| `windows.json` | 窗口数量、每个窗口的位置 / 尺寸 / 最大化状态 / 显示哪个便签 |
| `prefs.json` | 开机自启等偏好 |
| `log.txt` | 运行日志（排障用，超过 512KB 自动清空） |
| `runtime\` | 浏览器内核缓存（可随便删） |

路径：

- 安装版 → `%APPDATA%\NoMoreTomorrow-Data`（即 `C:\Users\你\AppData\Roaming\NoMoreTomorrow-Data`）
  - 卸载**不会**删除这个文件夹，便签不会因为卸载而丢。
  - 想让安装版也变成绿色版？在 exe 旁边手动新建一个 `NoMoreTomorrow-Data` 文件夹，它会优先用那个。
- 便携版 / 绿色版 → **exe 同目录**下的 `NoMoreTomorrow-Data\`

- **备份** = 直接复制整个 `NoMoreTomorrow-Data` 文件夹。
- **重置** = 删掉整个 `NoMoreTomorrow-Data` 文件夹（下次启动会从空便签重新开始）。
- **换机器** = 把 exe + 数据文件夹一起拷过去即可。

**关闭开机自启**：托盘菜单取消勾选，或删掉注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `com.nomoretomorrow.memo`。

## 五、源码与重新打包

```
Nomoretomorrow\
├─ Activities.html              ← 你原来的便签页面，未被修改，始终是唯一数据源
├─ release\                     ← 成品（安装包 / 便携版 / 绿色版 / 本说明）
└─ memo-app\                    ← 打包工程
   ├─ app\main.js               ← 主进程：单实例、多窗口、几何持久化、托盘、自启、文件存储
   ├─ app\preload.js            ← 把 localStorage 换成 JSON 文件仓库 + 多窗口实时同步 + 便签绑定
   ├─ app\shell.js              ← 注入的窗口外壳：拖动区、八向缩放热区、右上角按钮
   ├─ app\Activities.html       ← 由 pnpm sync 从上级目录复制进来（不要手改）
   ├─ assets\ build\            ← 图标（png / ico，由脚本生成）
   └─ scripts\                  ← 同步、生成图标、端到端测试工具（CDP / 窗口控制）
```

重新打包（需要 Node + pnpm）：

```powershell
cd memo-app
pnpm install                 # 装依赖（electron / electron-builder）
node node_modules\electron\install.js   # 若 electron 二进制没自动下载，手动补一次
pnpm sync                    # 把最新的 Activities.html 复制进 app\
pnpm dist                    # 产出到 dist\（安装包 + 便携版 + win-unpacked 绿色版）
```

- 改完 `Activities.html` 后只要 `pnpm sync` + `pnpm dist` 就进新包。
- 开发调试：`pnpm start`（直接跑源码，不等打包）。
- 重新生成图标：`pnpm icons`。
- 调试用的窗口/页面检查工具：`scripts\cdp.mjs`（连 Electron 的 remote-debugging 端口）、`scripts\win-ctl.ps1`（枚举/移动窗口、模拟真实鼠标拖动）。

## 六、已知限制

1. **体积**：成品约 96MB / 绿色版约 250MB（Electron 运行时就是这么重）—— 这是「一个 exe 即开即用 + 完整 Chromium 渲染 + 透明毛玻璃窗口」的代价。
2. **便携版启动慢**：单文件便携版每次启动都要把运行时解压到临时目录，实测约 12 秒；绿色版约 1.4 秒，安装版约 1～2 秒。日常用建议选绿色版或安装版。
3. **开机自启**走注册表 Run 键，登录后随系统启动。
4. 便签窗口是**透明无边框**窗口，没有系统标题栏，移动/缩放靠上面说的手柄和边缘热区。
